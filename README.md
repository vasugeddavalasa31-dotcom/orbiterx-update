This repository serves as the official public release channel and automated build pipeline for **OrbiterX Desktop** (macOS and Windows).

## 📥 Downloads
Download the latest prebuilt binaries from the **[Releases Page](https://github.com/vasugeddavalasa31-dotcom/orbiterx-update/releases/latest)**:

- **macOS (Apple Silicon)**: `OrbiterX-<version>-mac-arm64.dmg` / `OrbiterX-<version>-mac-arm64.zip`
- **macOS (Intel)**: `OrbiterX-<version>-mac-x64.dmg` / `OrbiterX-<version>-mac-x64.zip`
- **Windows**: `OrbiterX-<version>-win-x64.exe`

## 🔄 Auto-Update Distribution
All release manifests (`latest-mac.yml`, `latest-mac-x64.yml`, `latest.yml`) are published under GitHub Releases and served automatically to the OrbiterX Desktop app for seamless in-app auto-updates.
