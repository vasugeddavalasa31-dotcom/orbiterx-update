# OrbiterX Desktop Releases & Updates

This repository serves as the public release channel and automated build pipeline for **OrbiterX Desktop** (macOS and Windows).

## Auto-Update Distribution
All installers and release manifests (`latest-mac.yml`, `latest.yml`) are published here under GitHub Releases and served automatically to the OrbiterX Desktop app via the Railway Gateway.

### Supported Platforms
- **macOS (Apple Silicon)**: `.dmg` / `.zip` (ARM64)
- **macOS (Intel)**: `.dmg` / `.zip` (x64)
- **Windows**: `.exe` NSIS installer (x64)
